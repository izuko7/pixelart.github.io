# 🎨 Pixel Art Villages

> *Retour aux pixels, retour à l'essentiel — à la créativité et à l'art.*

## 📖 À propos du projet

**Pixel Art Villages** est un site dédié à la mise en valeur des images en pixel art.
Ce projet est ouvert à tous : que tu sois artiste, développeur ou simplement passionné,
tu es le bienvenu pour contribuer et enrichir cette galerie de créations pixélisées.

## 🌟 Objectif

Célébrer et promouvoir le **pixel art** sous toutes ses formes, en rassemblant
une communauté créative autour d'un art simple, nostalgique et intemporel.

## 🤝 Contribuer

Toute contribution est la bienvenue ! Que ce soit pour :
- Ajouter de nouvelles images pixel art
- Améliorer le design ou le code du site
- Proposer des idées ou des modifications

### 📋 Comment contribuer ?

1. **Fork** le dépôt
2. Crée ou bascule sur la branche `test`
   ```bash
   git checkout test
3. Effectue tes modifications
4. Push tes changements sur la branche test
5. Ouvre une Pull Request vers la branche
   
```  ⚠️ Important : Toutes les modifications doivent passer par la branche test et faire l'objet d'une Pull Request. Les contributions directes sur la branche principale ne seront pas acceptées.```
